## 关键经验(重要!)
1. **本环境安全删除机制危险**: `git rm`(任何形式,含 --cached)会清空整个 xqishell/ 目录!
   两次事故均由此引发。恢复: `git restore <dir>/`(索引在则可恢复)。以后禁用 git rm,
   用 git add -A 记录删除。
2. pip 安装/重装在本环境可能把包掏空(文件被拦截删除剩空壳目录)。
   iniconfig 曾因此损坏(pytest 报 SectionWrapper ImportError)。
   恢复: shutil.rmtree 空壳 + pip 重装(清华镜像可用)。
3. pytest tmp_path 清理在本环境触发 [safe-delete] 警告(无害,忽略)。
4. Edit 工具对同文件批量编辑易冲突("modified since read"),同文件改动应串行、必要时重读。
5. Bash heredoc 内含 Python 三引号易踩 bash EOF 冲突;脚本应先 Write 成文件再执行。
6. Windows 下 .venv/Scripts/python.exe 传参须用 Windows 风格路径(C:/...),git-bash 的 /c/ 路径会被错转。
